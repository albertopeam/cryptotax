# Language

All documentation (README.md, CLAUDE.md), code comments, docstrings, and user-facing messages must be written in **English**.

**Why:** The project is published publicly; English maximises accessibility for contributors.

**How to apply:**
- Write all new comments, docstrings, and print statements in English.
- Spanish fiscal law terms and references (LIRPF, IRPF, Art. 37.2, etc.) are proper names and may stay in Spanish — they have no English equivalent.
- Kraken-specific column names from the input CSV (`txid`, `refid`, `subtype`, `tradespot`, etc.) are external identifiers and must not be changed.
